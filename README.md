<h3 data-importer="text" align="left">Olá, este é o Web Ticketing!</h3>

###

<p data-importer="text" align="left">Este projeto é uma iniciativa entre a empresa Ipe Web e seus colaboradores.<br>A iniciativa do projeto, visa aprimorar o conhecimento dos colaboradores da empresa, criando um projeto com características reais.<br>Este projeto utiliza características como:<br><br>- Não obter informações de ferramentas de I.A.<br>- Documentação de tudo que for realizado no projeto.<br>- Testes unitários, utilizando o método TDD.<br>- Seguir o cronograma disponibilizado para o projeto.<br><br>Este projeto será testado para se eleger em uma classificação de acordo com seu desempenho e talvez será realmente utilizado futuramente.<br>O intuito desse projeto é garantir que, nós colaboradores da empresa, tenhamos uma grande base de conhecimento, sem o auxílio de qualquer ferramenta de IA.<br>Inclusive, esse README aqui, eu mesmo estou inventando em um site aleatório para criar README's legais.<br><br>Fique à vontade para ver o que construi, caso goste deixe sua ⭐.</p>
